# Review brief

Give a fresh reviewer this brief as its complete context. It inherits no conversation.

```text
Goal: <one sentence: what this artifact must achieve at this stage>
Criteria (observable, pass/fail):
  1. <e.g. first catch changes score 00 → 01 with visible feedback>
  2. <e.g. Esc pauses; HUD pixels unchanged for 1.5 s>
  3. <e.g. p95 frame interval ≤ 20 ms at 1280×900, DPR 1>
Reference: <path to concept image or visual targets>
Artifact: <running URL> and <source paths>
Tools: <browser tool available? screenshots? scripts in scripts/>
Report: for each criterion, what you did, what you observed, pass/fail, and one screenshot path.
       Then the single largest gap you would fix first. Do not fix anything.
```

Run the review at the first complete playable version and at each major polish milestone. When two comparable artifacts exist, present them anonymously as A and B and ask for a preference with reasons.
